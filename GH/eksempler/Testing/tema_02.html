Script kjører for tidlig

HTML-elementet er ikke lastet ennå

Oppgave: Sammenlign plasseringen av script og bruken av defer.
Diskuter: Hvorfor får vi null uten defer?

Prøv begge versjonene

1 · Feil versjon

Åpne i ny fane

For Console og mobiltest: Åpne i ny fane og trykk F12.

Vis index_feil.html 
<!DOCTYPE html><html lang="no"><head><meta charset="UTF-8"><meta name="viewport" content="width=device-width, initial-scale=1.0"><title>Script kjører for tidlig</title><link rel="stylesheet" href="style.css"><script src="script_feil.js"></script></head><body><h1>Script kjører for tidlig</h1><p><strong>Oppgave:</strong> I feil-versjonen kjøres script.js før knappen finnes. Sammenlign med riktig-versjonen som bruker defer.</p><button id="knapp">Klikk her</button><p id="resultat">Venter på klikk.</p></body></html>
Vis script_feil.js 
const knapp = document.querySelector("#knapp");
console.log("Knapp:", knapp);
knapp.addEventListener("click", function () {
  document.querySelector("#resultat").textContent = "Det virker!";
});
