Feil ID

JavaScript finner ikke knappen

Oppgave: Sammenlign id i HTML med querySelector i JavaScript.
Diskuter: Hva viser Console når elementet ikke finnes?

Prøv begge versjonene

1 · Feil versjon

Åpne i ny fane

For Console og mobiltest: Åpne i ny fane og trykk F12.

Vis index_feil.html 
<!DOCTYPE html><html lang="no"><head><meta charset="UTF-8"><meta name="viewport" content="width=device-width, initial-scale=1.0"><title>Feil ID</title><link rel="stylesheet" href="style.css"></head><body><h1>Feil ID</h1><p><strong>Oppgave:</strong> Klikk på knappen. Åpne Console (F12). Finn feilen og rett ID-en.</p><button id="sendKnapp">Send melding</button><p id="resultat">Ingen melding ennå.</p><script src="script_feil.js" defer></script></body></html>
Vis script_feil.js 
// FEIL: HTML-knappen heter sendKnapp, ikke knapp.
const knapp = document.querySelector("#knapp");
console.log("Fant knapp:", knapp);
knapp.addEventListener("click", function () {
  document.querySelector("#resultat").textContent = "Meldingen er sendt!";
});
