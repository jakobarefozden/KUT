Undersøk verdier med console.log

Input er tekst, ikke tall

Oppgave: Skriv 5 og se forskjellen mellom 55 og 10.
Diskuter: Hva gjør Number() med inputverdien?

Prøv begge versjonene

1 · Feil versjon

Åpne i ny fane

For Console og mobiltest: Åpne i ny fane og trykk F12.

Vis script_feil.js 
const felt = document.querySelector("#tall");
const knapp = document.querySelector("#doble");
knapp.addEventListener("click", function () {
  const verdi = felt.value;
  console.log("Input som tekst:", verdi, typeof verdi);
  // FEIL: + gir tekstsammenslåing når verdi er tekst.
  const resultat = verdi + verdi;
  console.log("Resultat:", resultat);
  document.querySelector("#resultat").textContent = "Dobbelt: " + resultat;
});

  const verdi = Number(felt.value);
