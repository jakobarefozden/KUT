Feil CSS-klassenavn

Knappen reagerer, men utseendet endres ikke

Oppgave: Sammenlign klassenavnet i CSS og classList.toggle().
Diskuter: Hvorfor vises ingen rød feil i Console?

Prøv begge versjonene

1 · Feil versjon

Åpne i ny fane

For Console og mobiltest: Åpne i ny fane og trykk F12.

Vis index_feil.html 
<!DOCTYPE html><html lang="no"><head><meta charset="UTF-8"><meta name="viewport" content="width=device-width, initial-scale=1.0"><title>Feil klassenavn</title><link rel="stylesheet" href="style.css"></head><body><h1>Feil klassenavn</h1><p><strong>Oppgave:</strong> Knappen virker, men bakgrunnen endres ikke. Sammenlign klassenavnet i CSS og JavaScript.</p><button id="tema">Bytt bakgrunn</button><p>Her skal bakgrunnen endre seg.</p><script src="script_feil.js" defer></script></body></html>
Vis script_feil.js 
const knapp = document.querySelector("#tema");
knapp.addEventListener("click", function () {
  // FEIL: CSS bruker mork, JavaScript bruker mørk.
  document.body.classList.toggle("mørk");
  console.log("Body-klasser:", document.body.className);
});
Vis style.css 
* {box-sizing:border-box} body {font-family:Arial,sans-serif;max-width:900px;margin:35px auto;padding:18px;line-height:1.5} h1 {color:#17365d} a:focus-visible,button:focus-visible {outline:3px solid orange;outline-offset:3px}
button {padding:12px;border:0;border-radius:8px;background:#2563eb;color:white} body.mork {background:#222;color:white}
